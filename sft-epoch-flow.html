What this epoch does—and deliberately does not do

It does

  • Teach controlled JSON targets with supervised next-token loss.
  • Update only attention LoRA adapters.
  • Use the frozen grouped validation split for epoch decisions.
  • Log the run and save a compact adapter.

It does not

  • Touch the frozen 300-row final evaluation set.
  • Change Qwen's original base weights.
  • Run the combined attention+MLP arm.
  • Run GRPO or use verifier rewards.
  • Automatically continue to epoch 2.
